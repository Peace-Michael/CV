2. NHANES Health Survey – Statistical Inference

2.1 Dataset & Research Questions

The NHANES dataset contains comprehensive health metrics from the U.S. population. Key research questions included: Is there a significant difference in BMI between males and females? Does age correlate with blood pressure? Are certain lifestyle factors associated with diabetes status?

Figure 1: Distribution of BMI by Gender (NHANES)

Two-sample t-tests, ANOVA, and chi-square tests were performed to evaluate relationships between variables.

2.3 Regression Modeling

A multiple linear regression model was fitted to predict BMI from age, gender, income, and physical activity.

# R code for NHANES regression model_bmi <- lm(BMI ~ Age + Gender + Income + PhysicalActivity, data = nhanes) summary(model_bmi) # R² = 0.312, Adj. R² = 0.308 # Age: β = 0.087, p < 0.001 # GenderMale: β = 1.245, p < 0.001
Key Finding: Age, gender, and income level are significant predictors of BMI. Physical activity was negatively associated with BMI, though the effect was modest (β = -0.52, p = 0.018).

3. European Stock Market – Time Series Analysis

3.1 Data Preparation

Daily closing prices for major European indices (FTSE 100, DAX, CAC 40, Euro Stoxx 50) from 2020–2025 were cleaned and converted to returns for analysis.

Figure 3: Time series of daily closing prices for European indices

3.2 Stationarity & ACF/PACF Analysis

Augmented Dickey-Fuller (ADF) tests confirmed that all index price series were non-stationary (p > 0.05) but became stationary after first-differencing (p < 0.01).

3.3 ARIMA Modeling & Forecasting

ARIMA models were fitted to each index. The optimal order was determined using AIC/BIC criteria.

# Python code for ARIMA from statsmodels.tsa.arima.model import ARIMA model = ARIMA(dax_returns, order=(1, 0, 1)) fit = model.fit() # AIC = -4123.45, BIC = -4108.12 forecast = fit.forecast(steps=30)
Forecast Insight: ARIMA(1,0,1) provided the best fit for all indices with an average RMSE of 0.012 for 30-day forecasts. The Euro Stoxx 50 showed the lowest volatility among the indices.

Figure 5: 30-day forecast for DAX returns with 95% confidence intervals

4. Customer Churn – Logistic Regression & Classification

4.1 Data Exploration

The telecom churn dataset included customer demographics, account information, service usage, and churn status. Exploratory analysis revealed that churn rate was 26.5% overall.

Figure 6: Churn distribution (26.5% churned, 73.5% retained)

4.2 Feature Engineering

  • Created tenure groups (< 6 months, 6–12 months, 1–2 years, > 2 years)
  • Encoded categorical variables (one-hot encoding)
  • Standardized numerical features for model stability
  • Engineered interaction terms between service types

4.3 Logistic Regression Model

A logistic regression model was built to predict churn probability. Variable selection used backward elimination based on AIC.

# R code for logistic regression model_churn <- glm(Churn ~ Tenure + MonthlyCharges + ContractType + ServiceCount + InternetService, family = binomial, data = churn_train) summary(model_churn) # Significant predictors (p < 0.05): # Tenure (negative), MonthlyCharges (positive), # ContractTypeMonth-to-month (positive), # Fiber optic (positive vs. DSL)

5.3 Factor Analysis

Exploratory factor analysis (EFA) was performed on 15 service usage variables to identify underlying dimensions of customer behavior. Three factors emerged:

  • Factor 1 (Digital Engagement): Online usage, data consumption, app usage
  • Factor 2 (Voice Services): Call volume, international calls, voicemail
  • Factor 3 (Premium Services): Streaming, security, cloud storage
Application: These factors informed targeted marketing campaigns—digital engagement customers responded best to email offers, while voice services customers preferred phone-based promotions.

7. Summary & Conclusions

7.1 Key Findings

  • NHANES: Significant gender-based differences in BMI and blood pressure; age and lifestyle factors are important health predictors.
  • Stock Market: European indices exhibit similar volatility patterns; ARIMA(1,0,1) provides reliable short-term forecasts.
  • Customer Churn: Contract type and tenure are the strongest predictors of churn; clustering reveals four distinct customer segments with varying risk profiles.

7.2 Technical Takeaways

  • R and Python are complementary tools for statistical analysis—R excels at hypothesis testing and modeling, while Python provides robust machine learning and data manipulation.
  • Regularization (L2) improved model generalization in logistic regression.
  • Time series analysis requires careful stationarity transformation and diagnostic checking.
